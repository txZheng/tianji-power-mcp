# 天机气象 · 电力提示

把天机气象 `/v2` 的预报要素转成面向电力资产的可读提示，供 agent 直接调用。这是一个 **stdio MCP 服务**，由本仓库 `.venv` 里的 Python 启动，工作目录为仓库根目录。

## 提供的工具

| 工具 | 用途 |
| --- | --- |
| `get_capability` | 返回已授权要素、已知不可用要素、调用预算与端点。开工前先调用，避免浪费额度 |
| `power_weather_hint` | 大风 / 覆冰 / 低温 / 高温 / 强降水 / 云遮挡提示，按事件合并并给出触发条件与证据 |
| `wind_solar_snapshot` | 风电、光伏关心的要素逐时快照，含轮毂风速、露点、风力等级等派生量 |
| `theoretical_power` | 理论出力演示：`kind="wind"` 按功率曲线、`kind="pv"` 按辐照×PR×温度修正 |
| `get_dataset` | 唯一取数入口，返回窗口内全部已授权要素；`fields` 投影列、`limit` 截断返回行数，响应里 `window_rows` 是本次窗口行数、`total_rows` 是缓存完整行数 |

坐标格式统一为 `经度,纬度`（经度在前）。

## 使用方式

直接用自然语言描述点位和时段即可，例如"太原明天有没有大风""112.55,37.87 未来 24 小时光伏云量怎么样"。工具返回里的 `data_gaps` 必须一并转述，它说明这次判定缺了哪些要素、结论因此打了几折。

## 限制

- 只做**基于天气数据的提示**，不做功率预测。`theoretical_power` 是默认功率曲线的演示映射，不是预测结果。
- 覆冰是无液态水含量要素时的气象条件代理，**不代表冰厚**；雾是代理判据，**不代表能见度**。
- 输出统一带"参考提示，非正式气象预报"的声明，不构成生产指令。
- 单进程调用预算默认 20 次（`TJW_MAX_CALLS`），相同参数 10 分钟缓存，被拒要素只烧一次额度。
- `hours` 是分析窗口：缓存按整天取数（问 6 小时实际取 24 小时），但各工具只分析请求的时段，整天余量仅用于同日复用。
